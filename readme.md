# Menú Digi - Sitio Web Gastronómico

Este proyecto es una plataforma web e-commerce diseñada para el sector gastronómico, permitiendo a los clientes visualizar la carta digital, promociones y ponerse en contacto con el comercio.

##  Características
- **Estructura semántica HTML5:** Uso adecuado de `<header>`, `<nav>`, `<main>`, `<section>`, `<article>` y `<footer>`.
- **Diseño Responsivo:** 
  - Sección de Productos maquetada con **Flexbox**.
  - Sección de Reseñas estructurada con **CSS Grid**.
  - Adaptado a dispositivos móviles, tablets y escritorio mediante Media Queries.
- **Formulario de Contacto:** Integración con Formspree para el procesamiento directo de mensajes.
- **Contenido Multimedia:** Mapa interactivo embebido mediante un `iframe` de Google Maps.
- **Estilos Modernos:** Tipografía `Poppins` de Google Fonts y botones con diseño *pill* estilizado.

##  Estructura del Proyecto
- `index.html`: Página principal con productos, banner y reseñas.
- `pages/contacto.html`: Formulario de contacto y ubicación.
- `css/styles.css`: Hoja de estilos externa unificada.
- `img/`: Carpeta con assets e imágenes optimizadas.
